Spritey is a game engine made in Godot that uses block coding, inspired by Scratch.
This is very unfinished and unstable. I probably won't continue this project.

**IMPORTANT MISSING FEATURES:**
- No deleting assets (sprites/frames/blocks)
- No saving projects
- No custom blocks (functions)
- Lots of general missing features

**KEEP IN MIND:**
- The code for the sprite effects shader is an AI-generated placeholder. I did this in order to test how the effects blocks would work, but I didn't feel like going through and fixing the code yet.
- This engine is slower than Scratch. Especially certain features like the "touching sprite" block, the bitmap editor, and the project drawing engine.

**AI DISCLOSURE:**
- All of the UI and images were made entirely without AI assistance.
- AI-generated code was used for prototyping/placeholders. But all of it has been thoroughly studied and then rewritten without the help of AI.
